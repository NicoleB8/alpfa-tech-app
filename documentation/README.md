# Markdown documentation.

## Reason

Because we're using typedoc, every time the command `npm run docs` is executed, typedoc generates documentation inside
the docs folder. The issue with that is that every markdown file is also erased.

## Solution

I decided to create a separate folder to store all of the documentation markdown. Which is this folder.

## Usage

To use or link this documentation markdown files, you simply need to add it in your comment when documenting using
typedoc.

### Example

```
/**
  * @document ../documentation/[insert file name here].md
  */

export function app(): void { ... }

```

This example above will provide a source markdown that will appear at the top of the documentation when you are viewing
it inside the documentation website generated by typedoc.
